# Diabetic Retinopathy Detection Using Deep Learning and MLOps

Five-level diabetic retinopathy severity grading of retinal fundus images (RetinaMNIST-224, MobileNetV2),
with a FastAPI backend, Streamlit dashboard, bulk labelled upload, retraining, model versioning and monitoring.

> **Experimental academic demonstration. Not a medical device and not a diagnosis.**
> Predictions must never be used for medical decisions.

Source code and documentation: see the project's GitHub repository.
